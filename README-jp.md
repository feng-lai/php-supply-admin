#### PHP Supply & Demand Admin Platform

これは PHP で構築された軽量な供給と需要管理プラットフォームです。製品の供給と需要情報、ユーザー投稿、基本的な事業運営を管理するためのバックエンド管理システムを提供します。小中企業向けに設計されており、供給と需要リソースのマッチングを合理化します。

##### 🌟 特徴

- 🔐 **管理者ダッシュボード**
  すべてのプラットフォーム操作を管理するシンプルでクリーンなバックエンドインターフェース。

- 📦 **供給・需要リスト**
  カテゴリやタグの指定が可能な供給/需要エントリの追加、編集、削除。

- 📝 **ユーザー投稿**
  管理者の承認待ちのユーザー投稿（供給または需要フォーム）をサポート。

- 🔍 **検索とフィルタリング**
  基本的なキーワード検索とカテゴリによるフィルタリングでデータのアクセシビリティを向上。

- 📊 **統計概要**
  供給総数、需要総数、ユーザーデータ、公開トレンドの概要。

- 🧩 **モジュール化されたアーキテクチャ**
  追加のモジュールや統合を簡単に拡張可能。

##### 🛠️ テクノロジー スタック

- **バックエンド:** PHP (ThinkPHP フレームワーク)
- **フロントエンド:** HTML + CSS + JavaScript (管理者 UI テンプレート)
- **データベース:** MySQL
- **その他:** jQuery, Bootstrap (レガシー UI 使用)

##### 🚀 クイックスタート

###### 前提条件

- PHP >= 7.1
- MySQL >= 5.6
- Apache / Nginx
- Composer (パッケージ管理用、オプション)

###### インストール

1. プロジェクトをクローン:

```bash
git clone https://github.com/feng-lai/php-supply-admin.git
cd php-supply-admin
```

2. MySQL データベースに SQL スキーマをインポート（例: `supply_admin.sql`）。

3. `/application/database.php` または `/config/database.php` でデータベースを構成します。

```php
'hostname' => '127.0.0.1',
'database' => 'your_db_name',
'username' => 'your_db_user',
'password' => 'your_db_pass',
```

4. `/public` ディレクトリをルートとしてウェブサーバー（Apache/Nginx）にデプロイします。

5. 管理パネルにアクセス:

```
http://yourdomain.com/admin
```

デフォルトの認証情報（DB シードに存在する場合）:
**ユーザー名:** admin
**パスワード:** admin123 *(最初のログイン後には変更してください)*

##### 📁 プロジェクト構造

```
php-supply-admin/
├── application/     # メインアプリケーションロジック (controllers, models, views)
├── addons/          # Web ルートディレクトリ
├── extend/          # 設定ファイル
├── public/          # 静的リソース (CSS, JS, 画像)
└── vendor/          # (オプション) データベーススキーマやシードファイル
```

##### 📌 注意事項

* このプロジェクトは内部または SME レベルのデプロイメントに適しています。
* より安全にするために、SSL を有効にし、生産環境で使用する場合は入力検証を追加してください。
* レガシーコードは新しい PHP バージョンやフレームワークに対応するために更新が必要になる場合があります。
