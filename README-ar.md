#### PHP Supply & Demand Admin Platform

**PHP Supply & Demand Admin Platform** هو منصة إدارة العرض والطلب خفيفة الوزن مبنية باستخدام PHP. تقدم نظام إدارة خلفية لإدارة معلومات العرض والطلب للمنتجات، وتقديمات المستخدمين، وعمليات الأعمال الأساسية. مصممة للشركات الصغيرة والمتوسطة، تساعد هذه النظام على تبسيط مطابقة موارد العرض والطلب.

##### 🌟 الميزات

- 🔐 **لوحة تحكم المدير**
  واجهة خلفية بسيطة ونظيفة لإدارة جميع عمليات المنصة.

- 📦 **قوائم العرض والطلب**
  إضافة وتحرير وحذف عناصر العرض والطلب مع تصنيف اختياري ووسوم.

- 📝 **تقديمات المستخدمين**
  دعم تقديم المحتوى من قبل المستخدمين (نماذج العرض أو الطلب)، في انتظار الموافقة من قبل المدراء.

- 🔍 **البحث والتصفية**
  البحث بالكلمات الرئيسية الأساسية وتصفية حسب الفئات لتحسين الوصول إلى البيانات.

- 📊 **نظرة عامة على الإحصائيات**
  نظرة عامة على العرض الكلي، والطلب الكلي، وبيانات المستخدم، واتجاهات النشر.

- 🧩 **هندسة قابلة للتوسع**
  يمكن توسيعها بسهولة بإضافة وحدات إضافية أو تكاملات.

##### 🛠️ التقنيات المستخدمة

- **الخلفية:** PHP (إطار عمل ThinkPHP)
- **الواجهة:** HTML + CSS + JavaScript (قوالب واجهة المدير)
- **قاعدة البيانات:** MySQL
- **أخري:** jQuery, Bootstrap (استخدام واجهة مستخدم قديمة)

##### 🚀 البدء السريع

###### المتطلبات المسبقة

- PHP >= 7.1
- MySQL >= 5.6
- Apache / Nginx
- Composer (اختياري، إذا كنت تريد إدارة الحزم)

###### التثبيت

1. انسخ المشروع:

```bash
git clone https://github.com/feng-lai/php-supply-admin.git
cd php-supply-admin
```

2. استورد ملف SQL للهيكل إلى قاعدة بيانات MySQL الخاصة بك (مثلاً: `supply_admin.sql`).

3. قم بتكوين قاعدة البيانات في `/application/database.php` أو `/config/database.php`.

```php
'hostname' => '127.0.0.1',
'database' => 'your_db_name',
'username' => 'your_db_user',
'password' => 'your_db_pass',
```

4. قم بنشر المشروع على خادم الويب الخاص بك (Apache/Nginx) مع توجيه `/public` كدليل جذر.

5. ادخل لوحة التحكم عبر:

```
http://yourdomain.com/admin
```

المعلومات الافتراضية للمصادقة (إذا كانت متاحة في بذور قاعدة البيانات):
**اسم المستخدم:** admin
**كلمة المرور:** admin123 *(يرجى تغييرها بعد تسجيل الدخول الأول)*

##### 📁 هيكل المشروع

```
php-supply-admin/
├── application/     # منطق التطبيق الرئيسي (controllers, models, views)
├── addons/          # دليل الجذر للويب
├── extend/          # ملفات التكوين
├── public/          # الموارد الثابتة (CSS, JS, الصور)
└── vendor/          # (اختياري) ملفات هيكل قاعدة البيانات أو البذور
```
